Récompenses et statistiques

Transparence

Les vues ne deviennent pas automatiquement de l’argent. Une récompense ne peut être créditée que si une règle vérifiable est définie, les données sont autorisées et le financement existe.

Statistiques

Les données seront demandées aux API officielles, selon les accès réellement accordés.

Calcul des récompenses

La formule, les plafonds, les contrôles anti-fraude et la source de financement devront être configurés avant lancement.

Aucun solde fictif ne sera présenté comme de l’argent réel. Cette version n’ajoute pas automatiquement de fonds.

Demander un retrait

Aucun dépôt

La demande sera enregistrée pour vérification. Aucun transfert réel n’aura lieu tant qu’un prestataire n’est pas connecté et que le solde n’est pas financé.
